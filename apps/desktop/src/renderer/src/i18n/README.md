# 界面语言

界面使用 Vue I18n，支持 `zh-CN`、`en-US`。设置中的 `auto` 跟随系统语言：中文系统显示中文，其余系统显示英文。`main.ts` 在挂载应用前读取已保存设置并加载两种语言资源，之后切换语言无需重新加载工作区。

## 新增文案

1. 在 `messages/` 对应领域的中英文资源中添加同名语义键，保持插值参数一致。使用完整句子，不拼接翻译片段。
2. 在组件或展示逻辑中使用有类型约束的翻译函数：

   ```ts
   import { createScopedTranslator } from "../i18n";

   const t = createScopedTranslator("components.settingsPage");
   ```

   命名空间来自实际资源目录；可用键由中文资源推导。跨领域共享文字可以使用顶层 `t`。

3. 持续显示的选项、标签和说明通过 `computed` 或 getter 读取 `t`，避免在模块初始化时保存翻译后的字符串。已有目录和文件投影使用 getter，语言切换不会替换索引快照或未保存草稿。
4. 跨进程错误根据稳定的 `ErrorPayload.code` 处理。不要通过中文或英文错误文字识别版本冲突等业务分支。设备同步进度、问题和历史说明携带有 schema 校验的消息标识及参数，在 Renderer 展示时翻译。

## 内容边界

翻译界面标签、说明、空状态、提示和原生菜单。作品正文、用户自定义名称、提示词、模型输出、文件路径、历史内容及持久化枚举保持原值。内置且可编辑的标签仅在稳定 ID 和原始默认值同时匹配时进行显示翻译，不将译文写回配置。

## 资源与验证

资源是静态 TypeScript 对象，按领域组织；Vite 插件将它们输出为独立 JSON 资源。生产和开发环境共用同一份资源，加载时校验键结构。启动体积检查分别统计业务 JavaScript（上限 1 MB）、新增 Vue I18n 运行库（独立构建分组，上限 60 KB）和两种语言数据（上限 800 KB），并限制总启动载荷。运行库分组不包含 Vue 或应用代码，所有资源均计入总量。

- `pnpm lint:i18n`：检查模板文字及展示属性中的遗漏。
- `pnpm test`：检查语言资源键、插值参数、消息语法、响应式显示、跨进程错误及既有业务行为。
- `pnpm build`：生成资源并检查启动体积。
- `node apps/desktop/scripts/electron-smoke.mjs --i18n-only`：在隔离的真实 Electron 窗口验证语言选择、设置与扩展页面、持久化以及作品内容不变。完整的 `pnpm smoke` 也包含该检查。

`lint:i18n` 是模板检查，不能替代对动态字符串、后端事件和用户内容边界的评审。新增长期显示的运行状态还需要验证切换语言后的更新行为。
